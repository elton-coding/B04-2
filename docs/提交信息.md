# 初赛 A 榜提交信息（v8）

## 作品名称

基于航迹锚定与多证据融合的电磁目标本体表征与态势生成智能体

## 作品简介（评审可见，≤500 字）

本作品面向多平台电子侦察脉冲数据（A 类）与目标航迹数据（B 类），构建“观测处理—目标理解—关联融合—本体表征—态势生成”的端到端智能体。观测处理：按到达时间与参数连续性把脉冲串接为相参处理间隔（CPI），抖动重频以脉冲序列平移对齐复核跨节点同源。目标理解：生成式波形指纹判定雷达型号；按数据自估的重访周期提取精确命中特征与全局驻留链，两级梯度提升树识别搜索/粗跟/精跟状态。关联融合：以 B 类航迹为几何锚点，计入航迹位置误差随距离折算的方位残差，结合型号一致、时序互斥与片段连续，迭代精修统一对象并完成对象—航迹关联。本体表征：辐射源、平台、航迹、节点及照射/伴随关系导出为 OWL/JSON-LD 知识图谱。态势生成：调用主办方提供的大模型撰写研判，失败时降级为规则模板。方案无场景硬编码，参数均由物理误差模型或数据在线估计；经时间分折交叉验证与去节点、漏脉冲、伪造航迹等压力测试验证泛化性，Docker 一键运行。

## 开源 / 第三方组件声明

核心算法（CPI 串接、波形指纹、航迹锚定与精修、状态识别、关联、本体与报告生成）均为自研，未使用任何预训练模型或第三方 API 密钥。依赖的开源组件：Python 3.11（python:3.11-slim 基础镜像，PSF）；numpy、pandas、scipy、scikit-learn、joblib、rdflib（BSD-3-Clause）；numba（BSD-2-Clause）；pyarrow、requests（Apache-2.0）；PyYAML（MIT）；matplotlib（Matplotlib License，BSD 风格）；知识图谱可视化页面引用 ECharts 5.5.0（Apache-2.0）。大模型仅通过评测环境注入的 LLM_BASE_URL / LLM_API_KEY / LLM_MODEL 环境变量调用主办方提供的 qwen3.8-27b，代码中未写死模型名、地址或密钥。
