# 实验记录

## 2026-11-17 里程碑 1：端到端基线 v1

### 关键数据发现
- 同一 CPI 内参数极差（实测，训练/测试一致）：RF ≈ ±2.5~2.9 MHz（**大于 D3 所述 ±0.5**）、PW ±0.1、幅度 ±0.5、DOA 空中 ±1.5° / 海面 ±3°。CPI 长度为 2^k（R01/R02 256、R03/R04 128、R05–R07 64、R08 32）。
- **P1A_test 存在约 2.9% 的随机漏脉冲**（与幅度无关），训练集几乎没有（0.02%）。不处理时测试集 CPI 被切碎（中位长度 17 vs 训练 64）。处理：串接允许间隔为 PRI 整数倍（k≤6），首间隔为倍数时自动修正 PRI；CPI 级 PRI/抖动估计改为漏脉冲鲁棒；训练时随机丢弃 3% 脉冲做增强。修正后测试 CPI 中位长度 62。
- 同一发射在多节点上 RF/PW/PRI 一致、到达时差仅为传播时延差 → 跨节点同源 CPI 匹配精度 99.4%。
- 全局约束：同一辐射源任一时刻只发射一个 CPI；两对象若 CPI 时间重叠而参数不同则不可能同源。计冲突时只用自身判型与对象型号一致的 CPI，避免少量误归属造成伪冲突（融合 ARI 0.73 → 0.82）。
- A-B 关联：真实对应对方位命中率均为 1.0；104005（R06，无航迹）与编队航迹方位重合，需散射等级规则与 min_hit=0.85 排除。

### 结果（P1A_train，前 300 s 训练 / 后 200 s 评估，模拟 3% 漏脉冲）
| 指标 | 值 |
|---|---|
| 聚类 ARI（各节点均值） / 成对 F1 / 纯度 | 0.897 / 0.911 / 0.969 |
| 型号准确率（按脉冲） | 0.975 |
| 状态准确率 / 宏 F1 | 0.957 / 0.755 |
| 融合 ARI / 成对 F1 | 0.807 / 0.826 |
| 关联准确率（对象 / 航迹） | 0.55 / 1.00 |
| 对象数（真值 11） | 20 |

P1A_test 推理：13.4 万 CPI → 20 个对象，16 条航迹中 11 条关联；单场景耗时约 45 s（本机）。

### 主要短板 → 里程碑 2
1. 过分割（20 vs 11）：节点内串接遇长时间不可见即断开；同型号多实例（R01×2、R03×2、R05×2）互相混入。计划改为"发射序列"级多节点联合跟踪（每个发射带多节点 DOA 向量）。
2. 过分割直接拉低关联对象准确率（多余对象只能 no_match）。
3. 状态 1（粗跟）宏 F1 低，需更好的跟踪段起始特征与 HMM 平滑。
4. 状态特征中滚动幅度计算较慢（~30 s），可向量化。
