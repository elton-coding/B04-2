# 实验记录

## 2026-11-17 里程碑 1：端到端基线 v1

### 关键数据发现
- 同一 CPI 内参数极差（实测，训练/测试一致）：RF ≈ ±2.5~2.9 MHz（**大于 D3 所述 ±0.5**）、PW ±0.1、幅度 ±0.5、DOA 空中 ±1.5° / 海面 ±3°。CPI 长度为 2^k（R01/R02 256、R03/R04 128、R05–R07 64、R08 32）。
- **P1A_test 存在约 2.9% 的随机漏脉冲**（与幅度无关），训练集几乎没有（0.02%）。不处理时测试集 CPI 被切碎（中位长度 17 vs 训练 64）。处理：串接允许间隔为 PRI 整数倍（k≤6），首间隔为倍数时自动修正 PRI；CPI 级 PRI/抖动估计改为漏脉冲鲁棒；训练时随机丢弃 3% 脉冲做增强。修正后测试 CPI 中位长度 62。
- 同一发射在多节点上 RF/PW/PRI 一致、到达时差仅为传播时延差 → 跨节点同源 CPI 匹配精度 99.4%。
- 全局约束：同一辐射源任一时刻只发射一个 CPI；两对象若 CPI 时间重叠而参数不同则不可能同源。计冲突时只用自身判型与对象型号一致的 CPI，避免少量误归属造成伪冲突（融合 ARI 0.73 → 0.82）。
- A-B 关联：真实对应对方位命中率均为 1.0；104005（R06，无航迹）与编队航迹方位重合，需散射等级规则与 min_hit=0.85 排除。

### 结果（P1A_train，前 300 s 训练 / 后 200 s 评估，模拟 3% 漏脉冲）
| 指标 | 值 |
|---|---|
| 聚类 ARI（各节点均值） / 成对 F1 / 纯度 | 0.897 / 0.911 / 0.969 |
| 型号准确率（按脉冲） | 0.975 |
| 状态准确率 / 宏 F1 | 0.957 / 0.755 |
| 融合 ARI / 成对 F1 | 0.807 / 0.826 |
| 关联准确率（对象 / 航迹） | 0.55 / 1.00 |
| 对象数（真值 11） | 20 |

P1A_test 推理：13.4 万 CPI → 20 个对象，16 条航迹中 11 条关联；单场景耗时约 45 s（本机）。

### 主要短板 → 里程碑 2
1. 过分割（20 vs 11）：节点内串接遇长时间不可见即断开；同型号多实例（R01×2、R03×2、R05×2）互相混入。计划改为"发射序列"级多节点联合跟踪（每个发射带多节点 DOA 向量）。
2. 过分割直接拉低关联对象准确率（多余对象只能 no_match）。
3. 状态 1（粗跟）宏 F1 低，需更好的跟踪段起始特征与 HMM 平滑。
4. 状态特征中滚动幅度计算较慢（~30 s），可向量化。

## 2026-11-17 里程碑 2：航迹锚定 + 波形指纹 + 驻留组 + 状态上下文（v2）

### 新发现（均经训练集真值验证）
- **CPI 首尾相接**：同一雷达连续发射，后一 CPI 首脉冲 = 前一 CPI 末脉冲 + PRI（μs 级精确）；以此链接的 CPI 99.99% 属同一辐射源。与跨节点同源发射合并为"驻留组"（纯度 99.7%）。
- **B 航迹可作几何锚点**：发射—航迹方位残差中位数 0.12–0.26°；按驻留组多节点联合残差 + 航迹型号（脉冲加权投票）指派，85% 脉冲可锚定，精度 96.8%。
- **判别式型号分类器会吸收训练场景类别先验**，导致 R03/R04 重叠区 CPI 被系统性判错；改为生成式"波形指纹"似然（无先验），对象级型号与融合均提升。
- **工作状态为边扫边跟交织**（50 ms 尺度切换）：跟踪驻留按 0.2/0.4 s 固定重访插入；粗跟 = 对某被跟踪目标跟踪段的前约 10 次驻留，被跟踪目标 = 该发射幅度最大的节点；同一发射各节点状态相同。
- **场景零点 bug**：floor 取整导致 1 s 偏差，改为四舍五入。
- P1A_test 的 B 数据存在多对近距（145–390 m）伴飞/伴航航迹（2/7、3/8、11/16），方位上难区分，锚定率 62%，由残差最小者关联。

### 结果（P1A_train，前 300 s 训练 / 后 200 s 评估，模拟 3% 漏脉冲）
| 指标 | v1 | v2 |
|---|---|---|
| 聚类 ARI / 成对 F1 | 0.897 / 0.911 | **0.987 / 0.989** |
| 型号准确率 | 0.975 | **0.995** |
| 状态准确率 / 宏 F1 | 0.957 / 0.755 | **0.988 / 0.897** |
| 融合 ARI / 成对 F1 | 0.807 / 0.826 | **0.988 / 0.989** |
| 关联准确率（对象 / 脉冲加权 / 航迹） | 0.55 / 0.54 / 1.00 | **1.00 / 1.00 / 1.00** |
| 对象数（真值 11） | 20 | **11** |

P1A_test：11 个对象，9 个关联航迹；WSL Docker 验证通过（42 s，峰值约 5 GB）。

## 2026-11-17 本体图谱 + 态势报告 + 智能体（v3）
- `situation.py`：态势要素抽取（节点/航迹运动方式、试验海区进出、航迹伴随/接近关系、跟踪照射关系、对象观测关系、型号把握度、关联候选），输出可核对的事实 JSON。
- `ontology.py`：电磁目标本体（13 类、14 种对象属性，含证据节点与认识论状态），导出 Turtle / JSON-LD / 交互式图谱 HTML。P1A_test：1395 个三元组。
- `report.py`：按 D4 八章结构生成 HTML 态势报告（地图、状态热图、表格），关键结论附 object_id/track_id 证据，标注观测事实/资料知识/推断/假设；`tools/html2pdf.ps1` 转 PDF。
- `agent.py`：可选大模型研判（仅读评测注入的环境变量；事实锁定校验——文中编号必须存在于事实，否则重试/降级模板；429 退避；去除思考链）。本地以模拟网关验证通过。
- 入口：`--task report`（或 `--report` / `B04_REPORT=1`）额外输出到 `<out-dir>/report/`；默认 `--task all` 只输出两张结果表。WSL Docker 两种模式均验证通过。

P1A_test 态势要点（详见 deliverables/P1A_test）：11 个辐射源对象，9 个关联航迹；7 条航迹无辐射（其中 7/8/16/15 与已关联航迹持续伴随，可能为静默编队平台）；多部雷达对本方 4 个观测节点形成持续跟踪照射。

## 2026-11-17 泛化验证与修复（v4）
新增 `tools/robustness.py`（3 折时间交叉验证：其余时段训练、测试时段截为独立场景；压力测试：关闭锚定/无 B/漏脉冲 10%/去节点/去一半航迹/伪造航迹）与 `src/b04/training.py`。结果见 `docs/泛化验证结果.md`。

### 发现的问题与修复
| 问题 | 原因 | 修复 |
|---|---|---|
| 第 2 折 R07/R08 伴航船合并（ARI 0.83、型号 0.86） | 航迹判型只用"几何唯一"单元投票，无航迹的 R06 夺走 R08 的航迹 11；宽松型号门限让 R08 组挂到 R07 航迹 | 航迹型号按"残差最小"判定（真实归属辐射源位于航迹上）；型号相容改为相对判据（≥最可能型号 30%）；仅高把握单元投票 |
| 关联：匈牙利算法强制指派导致整体错配 | "不关联"被当作代价 10，为凑满指派牺牲正确关联 | 每个对象增加代价 0.5 的"不关联"虚拟列；锚定结果作为关联先验；残差权重 0.01→0.1 |
| 航迹缺失时误锚定（去一半航迹 ARI 0.75） | 无航迹辐射源在方位偶然重合时被挂到他人航迹 | 片段级几何否决（节点内片段多数时间不符合该航迹则撤销） |
| 伴随航迹（测试集 2/7、3/8、11/16、13/15）令同一辐射源被拆分 | 新判型规则让静默伴随航迹也获得型号 | 一个辐射源只对应一条航迹：同型号、支撑单元重合 >50% 且距离中位数 <600 m 时，只保留残差更小者 |
| 异常输入（m0：toa 为 ns）导致卡死 | 每脉冲成独立 CPI，合并/并入为 O(n²) | toa 单位自检（相邻间隔中位数 >5000 按 ns 换算）；合并对象数上限 200、并入上限 500 + 向量化兜底 |

| 型号准确率 | 0.952（0.861） | **0.998（0.996）** |
